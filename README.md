# My Radio

A Java-based Android application for streaming and playing radio stations. Tunein does not support android 8 anymore and Radio Garden take minutes to load on my headunit. I need a radio app running smoothly on my resource limited headunit without advertisement. That is why this project created.

## Overview

My Radio is an Android application that allows users to browse and play radio streams from a list. The app provides an intuitive interface for selecting and listening to different radio stations.

## Features

- 📻 Browse and select from a list of radio streams
- 🎵 Audio playback with playback screen interface
- 📱 Android-compatible application
- 🔄 Stream selection functionality

## Known Issues

- **Android 8 Audio Bug**: No audio output when switching between streams. After playing a stream and navigating back to the stream list to select another stream, audio playback may fail on Android 8 devices.

## Technology Stack

- **Language**: Java
- **Platform**: Android

## Project Structure

This is a Java-based Android project containing the source code for the My Radio application.
